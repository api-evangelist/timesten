# TimesTen

> TimesTen is an in-memory relational database company that spun out of Hewlett-Packard Labs in 1996 as TimesTen Performance Software and was acquired by Oracle Corporation in 2005. The product continues as Oracle TimesTen In-Memory Database — a persistent, ACID-compliant OLTP database with SQL, replication, JSON support, and a Kubernetes operator. The company no longer operates independently and publishes no standalone web API; timesten.com redirects into oracle.com.

## APIs

- None: TimesTen is a client/server database accessed through SQL and database drivers, not a hosted web API.
